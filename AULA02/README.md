## Materiais Necessários

*   ESP32
*   Shield SATC

## Atividades Práticas

### Atividade 1: Leitura de Sensores via Serial

**Objetivo:** Utilizar a comunicação Serial para exibir os valores medidos pelos sensores de luminosidade (LDR) e temperatura e umidade (DHT11).

**Dicas:**
*   Verifique o esquemático da placa/shield no repositório para identificar as pinagens corretas.
*   Utilize a biblioteca apropriada para a leitura do sensor DHT11.

### Atividade 2: Publicação de Dados no ThingSpeak (WPA Personal)

**Objetivo:** Criar uma rede Wi-Fi WPA Personal usando os roteadores, conectar o ESP32 a essa rede e publicar as informações dos sensores em três canais distintos no ThingSpeak.

**Dicas:**
*   **Padrão da Rede Wi-Fi:**
    *   **SSID:** "SATC_Grupo_4"
    *   **Senha:** "12345678"
*   Utilize o cabo Ethernet de um dos computadores como WAN do roteador.

### Atividade 3: Publicação de Dados no ThingSpeak (WPA Enterprise)

**Objetivo:** Repetir a Atividade 2, mas utilizando a rede Wi-Fi WPA Enterprise disponível na **SATC** em vez da rede WPA Personal.

## Relatório da Atividade

O relatório desta atividade será avaliado como a nota **N1A** (Peso: **3**).

**Conteúdo Obrigatório do Relatório:**
*   Fotos da montagem do hardware.
*   Capturas de tela do funcionamento do código e da leitura dos dados.
*   Link(s) do(s) canal(is) do ThingSpeak com os dados publicados.
*   Código fonte completo e **comentado**.
*   Descrição dos problemas e soluções encontradas durante a atividade.

**Prazo de Entrega:**
O relatório deverá ser entregue no AVA até **18:59 do dia 26/03 (Aula 05)**.
